# MALBON CLUB CRM Strategy

Malbon Golf 会员增长与 CRM 策略展示页面。

## 在线预览

**[https://fengenjoy-coder.github.io/George/](https://fengenjoy-coder.github.io/George/)**

## 项目简介

本页面展示 Malbon Golf 的会员俱乐部体系，整合免费积分会员与 MBC 付费会员双轨制：

- **L1-L3 免费积分会员**：通过消费、行为和社交获得成长值与 Coins
- **L4 MBC Member**：年费 ¥30,000，享受四大核心权益
- **L5 Condor Member**：入会费 ¥100 万，全额抵扣消费，享受特定折扣

## 技术栈

- React 19 + Vite
- Tailwind CSS
- 纯前端静态页面

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
